# 数学物理笔记 · 细讲版（80 章）

> **从复数到 Galois** —— 一门写给愿意较真的自学者的现代数学进阶课。
>
> 深度锚对标俄罗斯数学物理高中（СУНЦ МГУ 一类）——**严格、不回避证明**；
> 每一条推导链都被拆成了「预备」与「完整推导」两步，**把每一步跳跃都摊开写**。

## 这一版改了什么、怎么读

原书 40 章，每章推导已经不跳步、不手挥——但对大多数自学的普通读者来说，从一个定义
到下一个定理之间的"合理"跳跃仍然太大：一步里悄悄用了三条前提，一个记号背后压缩了
好几次具体计算。这一版把**每一章拆成两章**：

- **「…·上（预备）」**：不给抽象定义，先用**具体数字、具体小例子**把要用到的操作
  演算一遍，把原书那一步压缩的推导拆回三五步，讲清楚"为什么会想到这样做"。
  读完这一章，你应该已经能**手算**出下一章要用的东西，只是还没看到它的一般证明。
- **「…·下（完整推导）」**：内容对应原书那一章，但推导本身也同步加细——
  在"预备"章打好的直觉和算例基础上，把严格定义、定理与证明**逐字不跳步**地过一遍。

**偶数章是原书内容的加细版，奇数章是它的具体铺垫。** 两章合起来读，才是完整的一章。

每一章内部仍是四段式：

1. **入口**：先给一道具体问题，不给定义
2. **结构**：从这道题里长出定义与定理——这一步才是现代数学
3. **证明**：完整、不跳步、不手挥、**不省中间步骤**
4. **练习**：基础 / 竞赛 / 研究，三档 —— **每题都给完整解答**

> 这是俄罗斯数学圈自己的做法：**从问题里长出结构**，而不是先讲抽象定义再补例子。

## 凡例

- 公式：全部写成 `$$...$$`（行内也是），不用单 `$`
- 术语：以 [术语对照表](glossary.md) 为准
- 练习：**每题都附完整解答**（基础 / 竞赛 / 研究 三档）
- 「…·上」与「…·下」是同一主题的两半，**先读上再读下**；「下」的"入口题"经常直接
  沿用"上"里已经手算过的那个例子，只是这次要求给出一般证明
