# 数学物理连载 · 重写课程

> **从复数到 Galois** —— 一门写给竞赛生拔尖者的现代数学进阶课。
>
> 内容重写自知乎专栏《[数学物理连载](https://zhuanlan.zhihu.com/ps-math)》（作者 菜场学院菜老师 @jRONI）；
> 深度对标俄罗斯数学物理高中（СУНЦ МГУ 一类）；
> 方法论依据 opc2 知识库（2,723 篇章级笔记）与四个数学专家工具。

## 这门课怎么读

每一章都是四段式：

1. **入口**：先给一道具体问题（奥赛题 / Квант / 教材例题），不给定义
2. **结构**：从这道题里长出定义与定理 —— 这一步才是现代数学
3. **证明**：完整、不跳步、不手挥
4. **练习**：基础 / 竞赛 / 研究，三档 —— **每题都给完整解答**

> 这是俄罗斯数学圈自己的做法：**从问题里长出结构**，而不是先讲抽象定义再补例子。

## 凡例

- 公式：全部写成 `$$...$$`（行内也是），不用单 `$`
- 术语：以 [术语对照表](glossary.md) 为准
- 练习：**每题都附完整解答**（基础 / 竞赛 / 研究 三档）
- 引用原专栏时标注 MP 编号，便于回查
