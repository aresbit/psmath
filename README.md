# 数学物理笔记 · 细讲版（80 章）

从复数到 Galois —— 一门写给愿意较真的自学者的现代数学进阶课。深度锚对标俄罗斯
数学物理高中（СУНЦ МГУ 一类）：严格、不回避证明。每一章都拆成「上（预备）」
与「下（完整推导）」两半——「上」用具体数字先手算一遍，「下」把同一件事写成
一般定义与完整证明，不跳步、不手挥。

**在线阅读**：<https://aresbit.github.io/psmath/>（GitHub Pages 开启后生效）

## 结构

- `docs/` —— 站点源目录，80 章正文 + `index.md`（目录）+ `glossary.md`（术语对照表）
- `_experts/` —— 各数学分支的方法论与参考素材
- `_check.py` / `_check_book.py` —— 单章 / 全书自查脚本（排版规则、编号规则、
  导航链接、练习-解答完整性）
- `_BRIEF_EXPAND.md` —— 本书 40→80 章扩写过程的写作规范（历史记录，供想了解
  编写过程的读者参考）

## 每章怎么读

1. **入口**：先给一道具体问题，不给定义
2. **结构**：从这道题里长出定义与定理
3. **证明**：完整、不跳步、不手挥
4. **练习**：基础 / 竞赛 / 研究，三档 —— 每题都给完整解答

## 自查

```bash
python3 _check.py docs/chXX_xxx.md      # 单章
python3 _check_book.py                   # 全书
```
